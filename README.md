# Neocities starter

This is a basic HTML/CSS/JS setup for a Neocities site.

## Run locally

From this folder, run:

```bash
python3 -m http.server 8080
```

Then open:

- http://localhost:8080

Stop the server with `Ctrl+C`.

## VS Code task (optional)

A task is included so you can start a local server from **Terminal → Run Task**:

- `Start local web server (Python)`
